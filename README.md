# MedGuard AI

AI-Assisted Medico-Legal Risk Prevention & Documentation Completeness Review for Early-Career Doctors.

## Overview
MedGuard AI is an educational and risk-prevention support system designed to help early-career practitioners audit consultation records.

> **Disclaimer:** MedGuard AI is an educational checklist tool. It does not evaluate clinical standards of care, diagnose patients, determine medical negligence, or replace professional legal counsel.

## Tech Stack
- Backend: Java 21, Spring Boot 3.x
- Build Tool: Maven
- Frontend: HTML5, CSS3, JavaScript
